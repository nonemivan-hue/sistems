# Учет транспортных карт - Инструкция по установке

## Системные требования

- Python 3.10 или выше
- pip (менеджер пакетов Python)
- 500 МБ свободного места на диске

## Установка

### 1. Распаковка архива

```bash
unzip transport_cards.zip
cd transport_cards
```

### 2. Создание виртуального окружения (рекомендуется)

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux/macOS
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск приложения

```bash
python app.py
```

Приложение будет доступно по адресу: http://localhost:5000

### 5. Вход в систему

- **Логин:** `admin`
- **Пароль:** `admin`

## Режимы хранения данных

Приложение поддерживает три режима хранения данных:

### A. JSON (по умолчанию)
Данные хранятся в папке `data/` в формате JSON. Не требует настройки.

### B. PostgreSQL
См. [docs/POSTGRESQL_MIGRATION.md](docs/POSTGRESQL_MIGRATION.md)

### C. MySQL
См. [docs/MYSQL_MIGRATION.md](docs/MYSQL_MIGRATION.md)

## Резервное копирование

В приложении есть встроенный модуль резервного копирования:
- Перейдите в раздел "Администрирование" -> "Резервное копирование"
- Создайте копию одной кнопкой
- Восстановите из сохраненного архива

## Безопасность

> **Важно:** В production-окружении обязательно:
> 1. Измените секретный ключ в `app.py` (переменная `app.secret_key`)
> 2. Используйте хеширование паролей (в текущей версии пароли хранятся в открытом виде для простоты)
> 3. Настройте HTTPS
> 4. Ограничьте доступ к папке `data/`

## Обновление

1. Создайте резервную копию через веб-интерфейс
2. Сохраните папку `data/`
3. Замените файлы приложения
4. Восстановите папку `data/`

## Поддержка

При возникновении проблем:
1. Проверьте логи в консоли
2. Убедитесь, что все зависимости установлены
3. Проверьте права доступа к папкам `data/` и `backups/`
