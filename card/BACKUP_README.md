# Настройка ежедневного резервного копирования

## Скрипт резервного копирования

Создан скрипт `backup_daily.sh` для автоматического ежедневного резервного копирования базы данных.

### Установка в cron

Для настройки ежедневного выполнения в 2:00 ночи выполните команду:

```bash
crontab -e
```

Добавьте следующую строку:

```
0 2 * * * /workspace/backup_daily.sh >> /workspace/backups/backup.log 2>&1
```

### Параметры

- **Время выполнения**: ежедневно в 02:00
- **Хранение**: резервные копии хранятся 30 дней
- **Формат имени**: `backup_daily_YYYYMMDD_HHMMSS.zip`
- **Расположение**: `/workspace/backups/`

### Ручное создание резервной копии

```bash
/workspace/backup_daily.sh
```

### Восстановление из резервной копии

1. Через веб-интерфейс: раздел "Резервное копирование" -> загрузить файл备份
2. Вручную: распаковать архив в директорию `/workspace/data/`
